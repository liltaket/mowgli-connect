Mowgli Connect

Your mower's own app, from anywhere.

Mowgli Connect lets you open your MowgliNext robot's web interface when you are away from home. You don't need a VPN, port forwarding or a new app, and nothing on the mower is exposed unprotected.

Read the code on GitHub How it is built

How it works

  1. Add the agent

    One small container runs next to MowgliNext on the robot and prints a pairing code.

  2. Pair with your account

    Sign in with GitHub and enter the code. The robot is now linked to you and nobody else.

  3. Open your robot

    Pick the robot from the list. You get the same dashboard, map and settings you use at home.

Agent on the robotchecks every request, then forwards it to the MowgliNext GUI

The login service only handles sign-in, pairing and a 60-second pass to open a robot. Live data, maps and commands go straight between you and your mower, never through it.

Built to be safe

  • Every request, including live data, is checked by the agent on the robot before it reaches the mower's software.
  • Each robot has its own key and its own tunnel. One robot can never reach another.
  • Remote joystick driving is off by default. Emergency stop, collision handling and safety stay on the robot and work without internet.
  • Sign-out and access removal reach the robot within minutes. If the robot loses contact with the login service, remote access stops instead of staying open.
  • Live data is compressed and heavy map layers are sent less often, so it also works on weak Wi-Fi or mobile data.
  • Open source, so anyone can check the code.

Privacy

Signing in with GitHub gives the login service your GitHub user id, username and display name. It stores those, which robots you have paired, and short-lived sign-in records. It does not see or store your mower's data, maps, location or camera. The service runs on Cloudflare.

Questions or removal requests: open an issue on GitHub.

Status

Prototype. It has been tested end to end through Cloudflare with the real MowgliNext interface and a simulated robot, but not yet on a real mower. Access is invite-only while it is being tested.

Mowgli Connect is an independent project and is not affiliated with Cloudflare or GitHub.
