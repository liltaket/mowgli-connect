Mowgli Connect

Your mower's own app, from anywhere.

Mowgli Connect lets you open your MowgliNext robot's own web interface from your phone or computer when you are away from home. No VPN, no Tailscale, no port forwarding and no new app. It is free.

Open your robot Install on your robot

Prototype, invite-only for now. Read the status before you install it.

How it works

  1. Install the agent

    One small container runs next to MowgliNext on the robot and prints a pairing code. It does not change MowgliNext.

  2. Pair it with your account

    Sign in with GitHub and enter the code. The robot gets its own address and is linked to you.

  3. Open your robot

    Press Open. You are logged in to the robot's own interface: the same dashboard, map and settings you use at home.

Install

You need a MowgliNext robot with Docker and Docker Compose v2, internet access, and an amd64 or arm64 CPU. The agent runs as its own Compose project in ~/mowgli-connect, so MowgliNext updates do not touch it.

  1. Run the installer on the robot

    Open a shell on the robot (for example over SSH) and run the command below. It downloads the script and lets you read it with less (press q to continue) before it runs. The installer asks for a robot name and whether to allow the remote joystick (default: no, recommended), starts the container and prints a pairing code.

    curl -fsSL https://liltaket.github.io/mowgli-connect/install.sh -o install.sh && less install.sh && sh install.sh

  2. Pair the robot

    Go to connect.bronc.app, sign in with GitHub (invite-only for now) and enter the pairing code. The robot gets its own address, such as https://kuffe.bronc.app.

  3. Open it

    Press Open next to your robot. You are logged in to its own interface, from anywhere.

Update: cd ~/mowgli-connect && docker compose pull && docker compose up -d

Uninstall: cd ~/mowgli-connect && docker compose down -v, then unlink the robot on connect.bronc.app.

Details, the joystick choice and troubleshooting are in the install guide. To run your own relay instead, see relay/README.md.

Agent on the robotchecks every request, then forwards it to the MowgliNext GUI

The login service (a Cloudflare Worker) only handles sign-in, pairing and a 60-second pass to open a robot. Live data, maps and commands travel between your browser and your mower through the tunnel and never pass through it.

Built to be safe

  • Every request, including live WebSocket data, is checked by the agent on the robot before it reaches the mower's software.
  • Each robot has its own Ed25519 key and its own tunnel. Access to one robot does not give access to another.
  • Remote joystick driving is off by default. It can only be turned on on the robot itself, when you install. The login service cannot enable it.
  • Emergency stop, collision handling and the firmware watchdog stay on the robot and work without internet.
  • The agent container locks its own network. Even someone who took over the Cloudflare account could not use the tunnel to reach your home network, the robot's other services or the robot's operating system. They could still use the mower's interface as the owner.
  • Sign-out and access removal reach the robot within minutes. If the robot loses contact with the login service, remote access stops instead of staying open.
  • Live data is compressed and heavy map layers are sent less often. In simulation the map page dropped from about 368 to about 40 KB/s, so it works on weak mobile data.
  • Open source. Several independent reviews by AI models are in the repository, and their findings were verified and fixed or documented. See docs/research.

Privacy

Signing in with GitHub gives the login service your GitHub user id, username and display name. It stores those, which robots you have paired, and short-lived sign-in records (hashed). It does not store your mower's data, maps, GPS position or telemetry, and that data does not pass through it.

Your traffic does go through Cloudflare. Cloudflare ends the encrypted connection (TLS) at its edge and forwards it through the tunnel, so Cloudflare can technically see it. The login service also runs on Cloudflare.

Questions or removal requests: open an issue on GitHub.

Status

Prototype. It has been tested end to end through real Cloudflare with the real MowgliNext interface and a simulated robot, from a phone on 5G. It has not been run on a real mower yet. Sign-in is invite-only while it is being tested.

The agent image is ghcr.io/liltaket/mowgli-connect-agent for linux/amd64 and linux/arm64. See the test report.

Mowgli Connect is an independent project and is not affiliated with Cloudflare or GitHub.
