How it works

Three steps, once. After that, your robot is a bookmark.

  1. Install the agent

    One small container runs next to MowgliNext on the robot. The installer asks for a name and whether to allow the remote joystick, then prints a three-word pairing code. MowgliNext itself is not changed.

  2. Pair it with your account

    Sign in at connect.bronc.app with GitHub and enter the code. The robot gets its own address, such as hedgehog.bronc.app, and is linked to you.

  3. Open your robot

    Press Open. You are signed in to the robot's own interface: the same dashboard, map and settings you use at home.

Install

The agent runs as its own Compose project in ~/mowgli-connect, so MowgliNext updates do not touch it. You need:

  • a MowgliNext robot with Docker and Docker Compose v2
  • internet access from the robot
  • an amd64 or arm64 CPU
  • a GitHub account that has been invited

Run it yourself

  1. Run the installer on the robot

    Open a shell on the robot, for example over SSH, and run the command below. It downloads the script and shows it to you in less first (press q to continue) before it runs. The installer asks for a robot name and whether to allow the remote joystick (default no, recommended), starts the container and prints a pairing code.

    curl -fsSL https://liltaket.github.io/mowgli-connect/install.sh -o install.sh && less install.sh && sh install.sh

  2. Pair the robot

    Go to connect.bronc.app, sign in with GitHub (invite-only for now) and enter the pairing code. The robot gets its own address, such as https://hedgehog.bronc.app.

  3. Open it

    Press Open next to your robot. You are signed in to its own interface, from anywhere.

Update
cd ~/mowgli-connect && docker compose pull && docker compose up -d
Uninstall
cd ~/mowgli-connect && docker compose down -v, then unlink the robot on connect.bronc.app.
Pairing code again
docker logs mowgli-connect

Where your data goes

Live data takes the short way: from your browser through Cloudflare's network straight to the agent on your robot.

  1. Your browserphone or computer
  2. Cloudflare Tunnelencrypted, no open ports at home
  3. Agent on the robotchecks every request, then forwards it to the MowgliNext interface

The login service stays out of the way. It is a Cloudflare Worker that only handles sign-in, pairing and a 60-second pass to open a robot. Maps, commands and live data travel between your browser and your mower through the tunnel and never pass through it.

Built to be safe

The mower keeps control of itself. Remote access is a checked, revocable door into its interface, nothing more.

  • Every request is checked on the robot.Including live WebSocket data. The agent verifies each one before it reaches the mower's software.
  • Each robot stands alone.It has its own Ed25519 key and its own tunnel. Access to one robot does not give access to another.
  • Remote joystick is off by default.It can only be turned on on the robot itself, when you install. The login service cannot enable it.
  • Safety stays on the mower.Emergency stop, collision handling and the firmware watchdog run on the robot and work without internet.
  • The container locks its own network.Even someone who took over the Cloudflare account could not use the tunnel to reach your home network, the robot's other services or its operating system. They could still use the mower's interface as the owner.
  • Sign-out reaches the robot within minutes.If the robot loses contact with the login service, remote access stops instead of staying open.
  • Light on mobile data.Live data is compressed and heavy map layers are sent less often. On a real mower the map page dropped from about 357 KB/s to about 7 KB/s through the tunnel.
  • Open source and reviewed.Several independent reviews by AI models are in the repository, and their findings were verified and fixed or documented. See docs/research.

Privacy

Signing in with GitHub gives the login service your GitHub user id, username and display name. It stores those, which robots you have paired, and short-lived sign-in records (hashed). It does not store your mower's data, maps, GPS position or telemetry, and that data does not pass through it.

Your traffic does go through Cloudflare. Cloudflare ends the encrypted connection (TLS) at its edge and forwards it through the tunnel, so Cloudflare can technically see it. The login service also runs on Cloudflare.

Questions or removal requests: open an issue on GitHub.

Why I made this

I wanted to check on my own mower from wherever I happened to be, without opening ports on my home network, setting up a VPN or paying for a service. So I built this for my own mower.

It is a side project and still early. If something breaks or looks wrong, open an issue and I will take a look.
